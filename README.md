# DRX Udhëzime Klinike

Mjet për përgatitjen dhe printimin e udhëzimeve klinike për konsultime specialistike.

> Prototip për testim. Mos përdorni të dhëna personale të pacientëve derisa të verifikohen kërkesat e sigurisë dhe përputhshmëria institucionale.

Kodi burimor transferohet nga projekti Lovable DRX Udhëzime.
