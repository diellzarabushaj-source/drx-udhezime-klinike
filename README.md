# DRX — Udhëzime Klinike

Aplikacion React + Vite për hartimin dhe printimin e udhëzimeve për konsultim specialistik në Kosovë. Kodi menaxhohet **vetëm në GitHub**.

## Funksionet

- Pamje e dokumentit A4 me rrjetin dhe rubrikat dygjuhëshe të udhëzimit në fotografi.
- Shabllone të disa specialiteteve me pyetje udhëzuese (jo diagnoza/gjetje të shpikura).
- Kontrolli i fushave, përgatitja e tekstit, kopjimi dhe printimi / PDF.
- Pa backend, pa llogari, pa ruajtje të të dhënave të pacientit. Nuk dërgon të dhëna personale në shërbime të tjera.

### Nisja

Node.js 22 ose më i ri:

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

### Status

Ky është **model elektronik orientues**, jo formular me numër serial, vulë ose certifikim të Ministrisë. Duhet auditim i sigurisë, vlerësim institucional dhe provë reale e printimit para përdorimit me të dhëna personale të pacientëve.
